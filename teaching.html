Quick start

I teach courses in astrophysics, computational physics and data science at undergraduate and postgraduate level, and build interactive simulations and computational labs that make difficult ideas tangible. My aim is curiosity, critical thinking and hands-on learning, through real-world applications and research-led mentorship.

Approach

Simulation-driven teaching

Simulations move students from passive observation to active reasoning: concept, computational experiment, then reflection.

Concept first

  • Theory checkpoint before each interactive module
  • Prompt-driven exploration with changing scenarios
  • Immediate reinforcement through adaptive quizzes

Computation built in

  • Numerical integration and ODE/PDE intuition
  • Scientific plotting and interpretation
  • Error analysis and model comparison

Tools

  • Python notebooks with cloud access
  • Simulations for class and self-study
  • Linux, Fortran, C++, Gnuplot and LaTeX
